# SW Android 1.1-termux

Pakiet `SW-Android.apk` zbudowano z kodu aplikacji w tym repozytorium przez
Gradle 8.7, JDK 17, Android SDK 35. Jest podpisany kluczem debug i przeznaczony
do ręcznej instalacji. Minimalny system: Android 7.0 (API 24).

Suma SHA-256 znajduje się w `SHA256SUMS`. Tokeny i lokalne pliki `.env` nie
wchodzą do APK. Serwer uruchamia się osobno w Termuxie — patrz `../TERMUX.md`.

Pakiet ma wersję 1.1-termux (kod 2). Aktualizacja aplikacji podpisanej innym
kluczem debug może wymagać odinstalowania poprzedniego pakietu i ponownego
wpisania ustawień. Baza Discord pozostaje na Discordzie.
